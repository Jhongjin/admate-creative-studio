# AdMate Presentation v2 Delivery Package

## Purpose

This package is the local executive-review delivery bundle for the AdMate presentation v2 draft. It is intended for Commander and executive review before final PPTX or Google Slides production.

## Data Handling Standard

- Restricted real case material is not used in the main deck.
- Main deck visuals use demo, anonymized, synthetic, or diagram-based material only.
- Real-world entity identifiers, operating figures, account identifiers, contact identifiers, credential strings, personal data, media-account identifiers, and collaboration-tool identifiers must not be exposed.
- External media examples should remain Lens synthetic output or approved sample imagery.
- Foresight figures are treated as anonymized aggregate examples, not performance guarantees.

## Git Commit Policy

PPTX, preview images, copied PNG assets, and delivery-package binaries are local deliverables, not source-of-truth text artifacts. They are intentionally not committed to git because the repo readiness guard protects against binary presentation assets being added by default.

The committed source-of-truth artifacts are the manifest and build notes. Commander can use this local delivery package for review and distribution.

## Human Review Before Final Presentation

- Confirm that all slide messages are appropriate for executive review.
- Confirm that no restricted real case material is needed in the main deck.
- Confirm that product screenshots remain demo, anonymized, synthetic, or diagram-based.
- Confirm that Slide 6, Slide 7, and Slide 8 asset usage matches the approved main-deck density.
- Confirm whether the final delivery should stay PPTX or be imported to Google Slides.
