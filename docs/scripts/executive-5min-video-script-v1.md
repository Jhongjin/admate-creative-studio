## Full Narration Script

### 0:00-0:15 Opening Title

본 영상의 presenter는 AdMate 설명을 위해 제작한 가상 캐릭터이며 실제 임직원이 아닙니다.

오늘 보고의 질문은 단순합니다. 왜 지금 AdMate가 필요한가입니다.

### 0:15-0:45 Opening: 왜 AdMate인가

광고 운영은 점점 더 복잡해지고 있습니다. 브리프를 해석하고, 정책을 확인하고, 세팅을 검수하고, 운영 중 변화를 모니터링하고, 캡처와 증빙을 남기고, 다시 성과를 분석해야 합니다.

이 과정에서 반복 업무는 많아지고, 중요한 판단은 사람마다 흩어지기 쉽습니다. AdMate가 해결하려는 문제는 사람을 대체하는 것이 아닙니다. 반복 업무를 줄이고, 운영자의 판단이 회사의 기준으로 남게 만드는 것입니다.

### 0:45-1:05 AdMate 정의

AdMate는 AI Agent 기반 광고 운영 자동화 플랫폼입니다.

기획부터 운영, 검수, 캡처, 학습까지 이어지는 광고 운영 흐름을 하나의 Agent loop로 연결합니다. 핵심은 무검토 자동 집행이 아니라, 더 안전하고 반복 가능한 운영 체계를 만드는 것입니다.

### 1:05-2:15 4개 제품

AdMate는 네 개의 product Agent로 설명할 수 있습니다.

첫 번째는 Compass입니다. Compass는 브리프와 운영 조건을 읽고 정책과 가이드 근거 확인의 출발점을 정리하는 Agent입니다. 캠페인 목적, audience, 채널 조건을 구조화해 플래너가 먼저 확인해야 할 기준을 빠르게 잡아줍니다.

두 번째는 Sentinel입니다. Sentinel은 세팅 검수와 운영 이상 감지 신호를 정리하는 운영 안전 Agent입니다. 세팅 누락, 승인 필요 항목, 운영 중 다시 봐야 할 신호를 앞단에서 확인해 운영 사고 가능성을 줄입니다.

세 번째는 Lens입니다. Lens는 운영 화면과 산출물을 비식별 기준으로 캡처하고 증빙 흐름을 정리하는 기록 Agent입니다. 캡처는 단순 저장이 아니라, 무엇을 확인했고 왜 남겼는지 설명 가능한 근거로 정리하는 과정입니다.

네 번째는 Foresight입니다. Foresight는 성과를 약속하지 않고, 다음 판단을 위한 예측 가설과 분석 관점을 제안하는 학습 Agent입니다. 실행 결과를 다음 브리프와 검수 기준으로 되돌려 운영자의 판단이 반복 가능한 기준으로 남게 합니다.

### 2:15-2:55 Agent Core: Openclaw와 Hermes

이 네 Agent를 하나의 운영 흐름으로 연결하는 것이 Agent Core입니다.

Agent Core는 내부적으로 Openclaw와 Hermes의 역할로 설명할 수 있습니다. Openclaw는 정해진 조건과 스케줄에 따라 업무를 실행하고 외부 시스템을 연결하는 workflow 엔진입니다. Hermes는 AI와 사용자 이벤트를 기억하고, 학습 후보를 검토 가능한 기준으로 정리한 뒤 승인된 내용만 반영하도록 돕는 지능과 메모리 엔진입니다.

임원 보고에서 중요한 점은 기술 이름 자체가 아닙니다. 중요한 것은 AdMate가 사용할수록 회사의 광고 운영 기준을 더 잘 남기고, 권한과 감사 로그 기반으로 안전하게 확장될 수 있다는 점입니다.

### 2:55-3:35 운영 Loop

AdMate의 운영 loop는 기획에서 시작합니다.

Compass가 브리프와 조건을 읽고 정책과 가이드 근거 확인의 출발점을 정리합니다. Sentinel이 세팅 검수 기준과 운영 이상 감지 신호를 앞단에서 확인합니다. 운영 중에는 필요한 변화와 위험 신호를 모니터링하고, Lens가 캡처와 증빙을 정리합니다. 이후 Foresight가 성과를 약속하는 것이 아니라 다음 판단을 위한 분석 관점과 예측 가설을 제안합니다.

그리고 이 모든 과정에서 운영자의 판단은 다음 브리프, 다음 검수 기준, 다음 학습 후보로 되돌아갑니다.

### 3:35-4:25 회사 경쟁력

AdMate의 경쟁력은 단순히 더 빠르게 처리하는 데서 끝나지 않습니다.

첫째, 운영 지식을 자산화합니다. 개인의 경험으로만 남던 판단 근거와 예외 기준을 회사가 다시 사용할 수 있는 기준으로 정리합니다.

둘째, 반복 업무를 줄입니다. 정책/가이드 근거 확인, 세팅 검수, 캡처, 보고 준비에 쓰던 시간을 줄이고, 플래너가 전략 판단과 운영 품질 개선에 더 집중할 수 있게 합니다.

셋째, 안전한 AI 운영을 전제로 합니다. AdMate는 ISMS, 권한, 승인 흐름, 감사 로그를 기반으로 운영되어야 합니다. 민감 정보 접근, 학습 후보 반영, 실행 판단은 사람 승인과 권한 기준 안에서 관리됩니다.

넷째, 비용과 ROI를 관리 가능한 기준으로 봅니다. ROI는 성과 약속이 아니라 절감 시간, 오류 예방, 운영 지식 축적 효과로 설명해야 합니다.

### 4:25-4:50 Roadmap

다음 단계는 세 가지 방향입니다.

첫째, Intelligence Library입니다. 승인된 메시지, 검수 기준, 운영 판단을 재사용 가능한 지식으로 정리합니다.

둘째, Report personalization입니다. 같은 운영 결과도 임원, 플래너, 실무 owner가 다르게 이해할 수 있도록 audience별 보고 구조를 정리합니다.

셋째, Creative Studio입니다. 제품 설명, presenter script, storyboard, shotlist를 안전한 기준 안에서 더 빠르게 만들 수 있게 합니다.

### 4:50-5:00 Closing

AdMate는 미디어플래너를 대체하는 플랫폼이 아닙니다.

반복 업무를 줄이고, 판단의 근거를 남기고, 플래너가 더 중요한 전략과 의사결정에 집중하게 만드는 AI Agent 기반 운영 파트너입니다.
