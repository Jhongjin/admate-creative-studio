# Planner 90s Video Script v1

작성일: 2026-05-07
상태: Gate Creative-Studio-3 draft
용도: 미디어플래너 대상 90초 내외 소개 영상 narration script
전제: 영상 생성, 외부 API 호출, 실제 asset 업로드 없이 문서 기준 script만 작성

## Safety Boundary

- 실제 내부 화면, 캠페인명, 광고주명, 계정 정보, 성과 수치, 민감 데이터는 사용하지 않는다.
- Presenter는 생성형 AI로 제작한 가상 캐릭터이며 실제 임직원이나 실제 플래너가 아니다.
- 플래너 대체, 완전 자동 운영, 성과 보장, 사람 승인 없는 학습/집행 표현은 사용하지 않는다.
- 화면 예시는 모두 abstract card, dummy label, sanitized mock 기준으로만 설명한다.

## Video Objective

미디어플래너가 AdMate를 "반복 확인을 줄이고 판단 시간을 늘려주는 AI 업무 파트너"로 이해하게 한다. 핵심은 일이 사라진다는 약속이 아니라, 정책 확인, 사전 검수, 운영 감지, 캡처/증빙, 예측/분석, 학습 루프가 한 흐름으로 정리된다는 점이다.

## Required Disclosure

영상 시작 또는 종료에 다음 문구를 표시한다.

`본 콘텐츠의 presenter는 생성형 AI로 제작한 가상 캐릭터입니다. 실제 인물 또는 임직원을 나타내지 않습니다.`

## Full Narration Script

### 0:00-0:08 Opening: 반복 확인 업무가 많은 현실

캠페인 운영에서 가장 피곤한 순간은 큰 판단보다 반복 확인이 쌓일 때입니다.

정책을 다시 보고, 세팅을 다시 확인하고, 캡처와 증빙을 남기고, 결과를 다시 정리해야 합니다.

### 0:08-0:18 AdMate 한 문장 소개

AdMate는 이런 반복 확인을 줄이고, 플래너가 더 중요한 판단에 집중하게 돕는 AI Agent 기반 광고 운영 플랫폼입니다.

플래너를 대체하는 도구가 아니라, 판단에 필요한 기준과 근거를 더 빠르게 준비하는 업무 파트너입니다.

### 0:18-0:31 Compass: 정책 확인

먼저 Compass가 브리프와 운영 조건을 읽고, 확인해야 할 정책과 제약 조건의 출발점을 정리합니다.

어디부터 봐야 하는지, 어떤 조건을 놓치면 안 되는지 먼저 잡아주는 역할입니다.

### 0:31-0:46 Sentinel: 사전 검수/운영 감지

그 다음 Sentinel이 사전 검수와 운영 감지를 돕습니다.

금지 표현, 세팅 누락, 승인 필요 항목을 미리 확인하고, 운영 중에도 다시 봐야 할 신호를 정리합니다. 단, 최종 판단과 승인은 항상 사람이 수행합니다.

### 0:46-0:58 Lens: 캡처/증빙

Lens는 캡처와 증빙을 보고 가능한 흐름으로 정리합니다.

무엇을 확인했고, 왜 남겼는지 함께 정리해 나중에 다시 찾는 시간을 줄입니다. 실제 내부 화면이나 계정 정보는 영상에 사용하지 않습니다.

### 0:58-1:12 Foresight: 예측/분석

Foresight는 결과를 해석하고 다음 액션의 가설을 세우는 데 도움을 줍니다.

성과를 보장하는 것이 아니라, 무엇을 더 봐야 하는지, 다음 운영에서 어떤 기준을 바꿔볼지 분석 관점을 제안합니다.

### 1:12-1:24 Agent Core: 내 판단이 다음 기준으로 쌓이는 구조

이 흐름을 Agent Core가 하나로 연결합니다.

플래너가 내린 판단은 한 번 쓰고 사라지는 메모가 아니라, 다음 브리프와 검수 기준으로 돌아오는 학습 후보가 됩니다. 그래서 쓸수록 팀의 운영 기준이 더 선명해집니다.

### 1:24-1:30 Closing

AdMate는 플래너를 대체하지 않습니다.

반복 확인은 줄이고, 전략과 판단에 더 집중하게 돕는 AI 업무 파트너입니다.

## Presenter Notes

- 임원용보다 조금 더 빠르게 말하되, 문장 끝은 또렷하게 닫는다.
- "내 일이 줄어든다"보다 "반복 확인이 줄고 판단 시간이 늘어난다"를 중심 표현으로 쓴다.
- 실제 경험담처럼 들리는 "제가 해보니" 표현은 쓰지 않는다.
- 제품명은 scene마다 하나씩만 강조한다.
- 성과 예측은 반드시 "가설" 또는 "분석 관점"으로 표현한다.
