# Presenter Persona Guide v1

작성일: 2026-05-06
대상: AdMate 발표/홍보용 가상 AI presenter

## 2026-06-08 Lua Positioning Update

루아는 AdMate 전용 presenter로만 한정하지 않는다. 루아는 Instagram을
주요 활동 채널로 하고 YouTube에도 같은 컨셉을 확장할 수 있는 AI
influencer / AI virtual creator다.

루아 채널의 기본 콘텐츠는 일상, 뷰티, 음식, office routine, 관심사,
브랜드/서비스 소개 활동을 포함할 수 있다. Nasmedia AdMate 소개는 루아의
활동 내역 중 하나로 다루며, 루아의 전체 정체성을 AdMate 설명용 캐릭터로
고정하지 않는다.

AdMate 콘텐츠에 루아를 사용할 때도 루아는 실제 임직원, 운영자, 고객,
광고주 담당자, 실제 외부 인플루언서가 아니다. AI-generated virtual
influencer disclosure와 sanitized mock-data boundary를 유지한다.

## 기본 원칙

AdMate presenter는 실제 인물이 아니라 생성형 AI로 만든 가상 브랜드 캐릭터다. 이름, 배경, 직책, 말투, 영상 설명 어디에서도 실제 임직원, 고객, 광고주, 외부 인플루언서처럼 오인되게 만들지 않는다.

## 후보 persona

### Working name

- 현재 asset 파일명에는 `lua`가 포함되어 있다.
- `Lua`는 asset 실험명으로만 취급한다.
- AdMate 공식 캐릭터명으로 쓰려면 별도 브랜드 승인과 사용 가이드가 필요하다.

### 역할 정의

- Executive Presenter: AdMate 전략, 리스크 관리, 운영 확장성을 설명한다.
- Planner Guide: 실무자가 브리프에서 스토리보드까지 이동하는 흐름을 안내한다.
- Product Narrator: 제품별 기능을 짧은 scene으로 설명한다.

## 시각 기준

### 권장

- Ivory shirt/blouse 계열의 차분한 business casual.
- 정면 또는 3/4 closeup, 안정적인 eye contact.
- neutral 또는 soft smile.
- generic studio, abstract office, 또는 비식별화된 mock background.

### 제한

- mirror selfie, beauty lipstick, private apartment 느낌은 외부 임원/제품 설명 영상에서는 제한한다.
- 실제 거리 표지, 상점명, 특정 지역명은 최종 영상에서 제거하거나 generic 배경으로 대체한다.
- deep V-neck, 지나친 lifestyle/beauty 연출은 AdMate corporate tone과 맞지 않을 수 있다.

## 일관성 기준

영상 reference로 사용할 경우 다음 항목을 shot마다 확인한다.

| 항목 | 허용 기준 | 실패 신호 |
|---|---|---|
| 얼굴 | 동일 인물로 인지되는 얼굴형, 눈매, 코/입 비율 | shot마다 나이, 얼굴형, 눈 크기가 달라짐 |
| 머리 | 어두운 갈색 긴 머리, 자연스러운 가르마 | 머리 길이/색이 갑자기 변함 |
| 의상 | ivory shirt/blouse 중심 | knit, blouse, shirt가 이유 없이 섞임 |
| 배경 | 비식별 generic background | 실제 사무실, 거리명, 상호, 내부 화면 노출 |
| 표정 | calm, confident, helpful | 과도한 beauty pose, 감정 과장, 부자연스러운 입 모양 |
| 손/소품 | 필요할 때만 자연스럽게 등장 | 손가락 오류, 제품 변형, 실제 브랜드 상품처럼 보임 |

## 사용 범위

### 허용

- 내부 moodboard
- 비식별 storyboard reference
- 가상 presenter concept 검토
- script tone alignment용 still reference

### 조건부 허용

- 내부 임원 보고 영상: 보안 checklist와 "가상 presenter" 고지 필요.
- 외부 홍보 영상: 브랜드, 법무, 보안 승인 필요.
- 제품 설명 영상: 실제 고객 후기나 임직원 발언처럼 보이지 않도록 script review 필요.

### 금지

- 실제 인물, 임직원, 광고주 담당자, 유명인 imitation.
- 실제 회사 직책 또는 실명을 붙이는 연출.
- AI presenter가 실제 고객 경험을 증언하는 형식.
- 사내 화면, 계정 정보, 캠페인 성과를 배경에 합성.
- 외부 AI tool에 민감자료와 함께 reference asset 업로드.

## 고지 문구 기준

### 내부 공유용

`본 영상의 presenter는 생성형 AI로 제작한 가상 캐릭터이며 실제 임직원이 아닙니다.`

### 외부 공개용

AdMate 전용 presenter 콘텐츠:

`본 콘텐츠의 presenter는 AdMate 설명을 위해 생성형 AI로 제작한 가상 캐릭터입니다. 실제 인물 또는 임직원을 나타내지 않습니다.`

루아 influencer 채널 콘텐츠:

`루아는 생성형 AI로 제작한 AI virtual influencer이며 실제 인물 또는 임직원을 나타내지 않습니다.`

### 영상 내 표기 위치

- 5분 임원 보고 영상: 시작 5초 이내 작은 caption, 마지막 credit에 재표기.
- 90초 플래너 소개 영상: 시작 또는 종료 caption 중 최소 1회, description에도 명시.
- social short cut: description만으로 부족할 수 있으므로 영상 내 caption 권장.

## Script voice

- Executive Presenter: "핵심은 더 빠른 제작보다, 반복 가능한 메시지 품질과 안전한 통제입니다."
- Planner Guide: "브리프를 넣으면, 보고용 메시지와 스토리보드 초안까지 한 번에 정리합니다."
- Product Narrator: "AdMate는 민감한 캠페인 정보를 드러내지 않고도, 설명 가능한 creative story를 만듭니다."

## 톤 분리 기준

| 구분 | Executive 5min | Planner 90s |
|---|---|---|
| 목적 | 비전, 운영 통제, 성과/로드맵 판단 | 당장 쓸 수 있는 업무 흐름 이해 |
| 말투 | 절제된 보고형, 근거 중심 | 빠르고 실무적인 안내형 |
| 강조점 | 4개 product pillar, Agent Core, governance | 반복업무 감소, 정책 확인, 검수, 캡처, 예측, 학습 루프 |
| 금지 표현 | 실제 임원/직원 발표처럼 보이는 직함 | 실제 플래너가 경험담을 말하는 듯한 1인칭 후기 |
| 의상/배경 | ivory shirt, generic studio, boardroom-safe | ivory shirt/blouse, 밝은 generic workspace |

## 최종 확인 질문

- 시청자가 presenter를 실제 직원으로 오해할 가능성이 있는가?
- 배경이나 자막에 내부자료가 보이는가?
- 캐릭터명, 의상, 표정이 AdMate brand tone과 맞는가?
- 각 shot의 얼굴과 의상이 같은 캐릭터로 유지되는가?
- 고지 문구가 영상 또는 description에 남아 있는가?
