# Planner 90s Storyboard v1

작성일: 2026-05-06
목적: 미디어플래너가 반복업무 감소, 정책 확인, 검수, 캡처, 예측, 학습 루프를 중심으로 AdMate Creative Studio Agent의 실무 가치를 90초 안에 이해하게 한다.

## 톤

- 실무적이고 빠르다.
- "내가 당장 어디에 쓰나"가 먼저 보이게 한다.
- 임원용 영상보다 가볍지만, 과장된 AI magic tone은 피한다.
- 예시는 모두 dummy campaign과 generic brand로 구성한다.

## 핵심 메시지

브리프를 넣으면, AdMate Creative Studio Agent가 반복 작업을 줄이고 정책 확인, 검수, 캡처, 예측, 학습 루프를 한 흐름으로 정리한다. 내부자료를 노출하지 않고도 플래너가 설명 가능한 creative narrative를 빠르게 만든다.

## Presenter Direction

- Primary reference: `lua_brand_safe_profile_v1_ivory_shirt.png`

- Avoid: lipstick product, mirror selfie, Hannam street, Lua logo card
- Voice: friendly, precise, not influencer-like.

## Script Draft

"캠페인 브리프가 들어오면, 가장 먼저 필요한 건 멋진 영상이 아니라 반복 업무를 줄이는 설명 가능한 구조입니다. AdMate Creative Studio Agent는 목적, audience, 채널, 제약을 정리하고, 정책 확인과 검수 항목을 분리합니다."

"그 다음 executive tone과 planner tone을 나눠 script 초안을 만듭니다. 임원 보고에는 전략과 통제를, 실무 소개에는 바로 쓸 수 있는 흐름을 강조합니다."

"Storyboard는 intro, problem, solution, next action으로 정리됩니다. 캡처와 판단 근거는 보고 가능한 형태로 남기고, 예측은 성과 보장이 아니라 다음 실행을 위한 가설로 다룹니다."

"실행 후에는 배운 점이 다음 브리프와 검수 기준으로 돌아옵니다. 실제 광고주명, 계정 정보, 성과 수치, 내부 화면은 제외하고, 승인된 메시지와 dummy mock만 사용합니다."

"결과적으로 플래너는 빈 화면에서 시작하지 않습니다. 검토 가능한 creative narrative에서 시작합니다."

## 길이 변형

- 60초 버전: problem 설명을 줄이고 storyboard 결과 중심.
- 90초 버전: planner workflow와 safety gate를 균형 있게 포함.
- 120초 버전: product별 설명 구조와 예시 script를 추가.
