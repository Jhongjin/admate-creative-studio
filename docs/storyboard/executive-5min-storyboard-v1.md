# Executive 5min Storyboard v1

작성일: 2026-05-06
목적: AdMate 비전, 4개 product pillar, Agent Core, 성과/로드맵을 임원에게 5분 내외로 설명한다.

## 톤

- Boardroom-ready, concise, calm.
- 과장된 AI demo보다 통제 가능한 업무 체계와 리스크 관리 강조.
- 실제 캠페인/광고주/내부 화면은 쓰지 않고, sanitized mock과 abstract workflow를 사용한다.
- Presenter는 가상 캐릭터임을 시작부 또는 종료부에 고지한다.

## 핵심 메시지

AdMate Creative Studio Agent는 광고 운영 아이디어를 안전하고 일관된 creative narrative로 바꾸는 내부 업무형 AI studio다. 빠른 제작보다 중요한 것은 메시지 품질, 반복 가능성, 보안 통제, 그리고 제품 로드맵과 성과 학습을 하나의 Agent Core로 연결하는 것이다.

## Presenter Direction

- Primary reference: `lua_brand_safe_profile_v1_ivory_shirt.png`
- Expression: neutral confidence, soft smile only at closing.
- Wardrobe: ivory shirt/blouse. cream knit, lipstick, mirror selfie는 사용하지 않는다.
- Background: generic bright studio 또는 abstract office. 실제 사무실 합성은 보안 검수 전 금지.

## Script Draft

### Opening

"AdMate Creative Studio Agent는 광고 운영 아이디어를 보고 가능한 creative story로 정리하는 내부 AI studio입니다. 핵심은 단순히 영상을 빨리 만드는 것이 아니라, 메시지 품질과 보안 통제를 반복 가능한 방식으로 만드는 것입니다."

### Problem

"캠페인 설명은 audience에 따라 달라집니다. 임원은 전략과 리스크를 보고 싶어 하고, 플래너는 바로 쓸 수 있는 브리프와 메시지 구조를 원합니다. 하나의 스크립트로 두 audience를 모두 만족시키기는 어렵습니다."

### Solution

"Agent는 브리프를 구조화하고, AdMate 제품별 설명을 정리한 뒤, 임원용과 실무자용 스토리보드를 분리합니다. 내부 화면이나 광고주 정보를 그대로 쓰지 않고, 승인된 메시지와 비식별 mock으로 설명합니다."

### Safety

"AI presenter는 실제 인물이 아니라 가상 브랜드 캐릭터입니다. 영상에는 이 사실을 명시하고, 사무실 배경, URL-to-video, reference image 사용은 모두 보안과 초상권 기준을 통과해야 합니다."

### Close

"다음 단계는 approved message library와 dummy campaign dataset을 만들고, 사람이 통제하는 최종 편집 workflow로 연결하는 것입니다. 빠르게 탐색하되, 신뢰할 수 있게 통제합니다."

## 필수 고지

`본 영상의 presenter는 생성형 AI로 제작한 가상 캐릭터이며 실제 임직원이 아닙니다.`

## 금지 요소

- 실제 dashboard 캡처
- 캠페인명, 광고주명, 계정명
- 실제 임직원처럼 보이는 직함/이름
- 민감 수치, budget, performance, contract detail
- URL-to-video output을 검수 없이 최종본으로 사용
