## Script Direction

### Opening

AdMate는 AI Agent 기반 광고 운영 자동화 플랫폼입니다. 오늘 보고의 질문은 왜 지금 AdMate가 필요한가입니다.

### Problem

광고 운영은 브리프 해석, 정책/가이드 근거 확인, 세팅 검수, 운영 감지, 캡처/증빙, 분석과 학습이 계속 이어지는 업무다. 반복 업무가 늘어나면 중요한 판단이 사람마다 흩어질 수 있다.

### Product Flow

Compass는 정책/가이드 근거 확인의 출발점을 정리한다. Sentinel은 세팅 검수와 운영 이상 감지 신호를 정리한다. Lens는 캡처와 증빙을 비식별 기준으로 정리한다. Foresight는 성과를 약속하지 않고 다음 판단을 위한 예측 가설과 분석 관점을 제안한다.

### Agent Core

Agent Core는 Compass, Sentinel, Lens, Foresight를 하나의 운영 loop로 연결한다. Openclaw는 조건과 스케줄에 따라 업무를 실행하고 기록하는 내부 실행 엔진이며, Hermes는 운영 지식과 판단 기준을 축적하는 내부 지능/메모리 엔진이다.

### Safety And Value

AdMate는 사람 승인, 권한, 감사 로그를 전제로 운영되어야 한다. 실제 캠페인명, 광고주명, 계정 정보, 내부 화면, 성과 수치는 영상에 사용하지 않는다.

### Closing

AdMate는 미디어플래너를 대체하지 않는다. 반복 업무를 줄이고 판단의 근거를 남겨, 더 중요한 전략과 의사결정에 집중하게 만드는 AI Agent 기반 운영 파트너다.
