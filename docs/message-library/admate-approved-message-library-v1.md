# AdMate Approved Message Library v1

작성일: 2026-05-07
상태: Gate Creative-Studio-8 aligned
용도: AdMate 홍보, 임원 보고, 미디어플래너 교육 영상에서 반복 사용할 승인 메시지 기준

## 사용 원칙

이 문서는 영상, 발표 자료, script 초안, shotlist 자막에 재사용할 수 있는 기본 메시지 library다. 실제 캠페인명, 광고주명, 계정 정보, 성과 수치, 내부 화면 설명은 포함하지 않는다. 모든 문장은 가상 presenter가 말할 수 있는 안전한 범위로 작성한다.

## 최상위 메시지

### Primary Message

AdMate는 AI Agent 기반 광고 운영 자동화 플랫폼입니다.

### Expanded Message

AdMate는 기획부터 운영, 검수, 캡처, 학습까지 이어지는 광고 운영 흐름을 AI Agent로 연결합니다. 미디어플래너를 대체하는 도구가 아니라, 반복 업무를 줄이고 운영자의 판단이 다음 기준으로 축적되도록 돕는 파트너입니다.

### Short Brand Copy

- 기획부터 학습까지, 광고 운영을 하나의 AI Agent 흐름으로 연결합니다.
- 반복 업무는 줄이고, 운영자의 판단은 더 잘 남깁니다.
- AdMate는 미디어플래너를 대체하지 않습니다. 더 안전하고 반복 가능한 운영을 돕습니다.
- 정책/가이드 근거 확인, 세팅 검수, 캡처, 예측 가설, 학습 후보를 하나의 운영 루프로 정리합니다.

## Approved Sentence Bank

### Opening

- AdMate는 광고 운영의 반복 업무를 AI Agent 흐름으로 정리하는 플랫폼입니다.
- 오늘은 AdMate가 기획, 운영, 검수, 캡처, 학습을 어떻게 연결하는지 소개하겠습니다.
- 핵심은 무검토 자동 집행이 아니라, 더 안전하고 반복 가능한 운영 체계를 만드는 것입니다.

### Problem

- 광고 운영은 작은 반복 업무와 중요한 판단이 계속 섞이는 일입니다.
- 정책/가이드 근거 확인, 세팅 검수, 캡처, 보고 준비가 분산되면 운영 지식이 사람마다 흩어질 수 있습니다.
- 내부 화면과 민감 데이터를 그대로 쓰지 않으면서도, 설명 가능한 운영 흐름이 필요합니다.

### Solution

- AdMate는 반복되는 확인 작업을 줄이고, 운영자의 판단이 다음 기준으로 남도록 돕습니다.
- Compass, Sentinel, Lens, Foresight는 각각 근거 확인, 안전 검수, 기록, 예측 가설을 맡고, Agent Core가 이를 하나의 흐름으로 연결합니다.
- 운영자는 최종 판단을 유지하면서도 더 빠르게 검토하고 더 일관되게 기록할 수 있습니다.

### Safety

- AdMate는 사람 승인과 권한 기준을 전제로 운영되는 AI Agent 체계를 지향합니다.
- 실제 캠페인명, 광고주명, 계정 정보, 내부 화면은 영상과 교육 자료에서 사용하지 않습니다.
- 이 영상의 presenter는 생성형 AI로 제작한 가상 캐릭터이며 실제 임직원이 아닙니다.

### Closing

- AdMate의 목표는 사람을 대체하는 것이 아니라, 운영자가 더 중요한 판단에 집중하게 만드는 것입니다.
- 반복 업무는 줄이고, 판단의 근거는 남기고, 다음 운영 기준은 더 선명하게 만듭니다.
- AdMate는 빠른 실행과 안전한 통제를 함께 갖춘 광고 운영 Agent 플랫폼으로 발전합니다.

## 승인된 표현과 주의 표현

| 사용 가능 | 피해야 할 표현 | 이유 |
|---|---|---|
| 반복 업무를 줄입니다. | 모든 업무를 무검토로 자동 집행합니다. | 사람 승인 없는 자동 집행처럼 오해될 수 있음 |
| 다음 판단을 위한 예측 가설을 제안합니다. | 성과를 약속합니다. | 실제 성과 약속 표현 금지 |
| 운영자의 판단을 학습 후보로 정리합니다. | AI가 알아서 학습하고 집행합니다. | 승인 없는 학습/집행으로 오해될 수 있음 |
| 권한과 감사 로그 기반으로 관리합니다. | 누구나 자유롭게 모든 데이터를 봅니다. | 권한 통제 원칙과 충돌 |
| 가상 presenter가 설명합니다. | AdMate 직원이 직접 설명합니다. | 실제 직원 오인 위험 |

## Script 작성 체크

- 최상위 메시지는 첫 15초 안에 1회만 명확히 말한다.
- 제품명은 한 scene에 1개씩만 소개한다.
- 임원용 script는 경쟁력, 통제, 비용, 로드맵을 우선한다.
- 플래너용 script는 시간 절감, 사고 예방, 캡처, 분석 준비를 우선한다.
- 모든 script에는 가상 presenter 고지, dummy visual/data 고지, 민감 정보 비사용 원칙을 포함한다.
