# Media Planner Message Bank v1

작성일: 2026-05-07
상태: Gate Creative-Studio-8 aligned
용도: 미디어플래너용 1-2분 소개 영상, 교육 영상, onboarding script에 사용할 승인 메시지

## Planner Tone

플래너용 메시지는 "내 업무에서 바로 어디에 쓰는가"를 먼저 보여준다. 과장된 AI 홍보보다 반복 업무 감소, 사고 예방, 검수 준비, 캡처, 분석 지원을 구체적으로 말한다.

## Core Narrative

AdMate는 미디어플래너를 대체하지 않습니다. 정책/가이드 근거 확인, 세팅 검수, 캡처, 분석 준비처럼 반복되는 업무를 줄이고, 운영자가 내린 판단이 다음 기준의 학습 후보로 정리되도록 돕습니다.

## Message Pillars

| Pillar | 승인 메시지 | 실무자에게 주는 의미 |
|---|---|---|
| 정책/가이드 근거 확인 | Compass는 브리프와 운영 조건에서 확인해야 할 정책/가이드 근거의 출발점을 정리합니다. | 어디부터 확인해야 하는지 빠르게 잡습니다. |
| 세팅 검수와 운영 이상 감지 | Sentinel은 세팅 누락, 승인 필요 항목, 운영 중 다시 봐야 할 이상 신호를 정리합니다. | 작은 실수가 운영 사고로 커지기 전에 확인할 수 있습니다. |
| 캡처/증빙 자동화 | Lens는 캡처와 변경사항, 검수 메모를 보고 가능한 흐름으로 정리합니다. | 나중에 "어디까지 확인했는지"를 찾는 시간을 줄입니다. |
| 성과 예측/분석 지원 | Foresight는 성과를 약속하지 않고 다음 판단을 위한 예측 가설과 분석 관점을 제안합니다. | 결과를 해석하고 다음 액션을 정하는 데 도움을 줍니다. |
| 판단 기준 축적 | Agent Core는 운영자의 판단을 다음 브리프와 검수 기준의 학습 후보로 되돌립니다. | 개인 경험이 팀의 반복 가능한 기준으로 남습니다. |

## Approved Planner Sentences

### Opening

- AdMate는 플래너의 반복 업무를 줄이고, 더 중요한 판단에 집중하게 돕는 AI Agent 플랫폼입니다.
- 캠페인 브리프가 들어오면, AdMate는 먼저 확인해야 할 정책/가이드 근거와 검수 항목을 정리합니다.
- 중요한 것은 AI가 대신 결정하는 것이 아니라, 플래너가 더 빠르게 판단할 수 있게 만드는 것입니다.

### Compass: Policy / Guide Source Check

- Compass는 브리프와 운영 조건을 읽고 정책/가이드 근거 확인의 출발점을 정리합니다.
- 정책/가이드 근거 확인이 뒤로 밀리면 수정 비용이 커질 수 있습니다. AdMate는 이 확인을 앞단으로 끌어옵니다.
- Compass는 전략을 자동 확정하지 않고, 사람이 판단할 수 있는 확인 기준을 제공합니다.

### Sentinel: Setup QA and Anomaly Signal

- 세팅 사고는 작은 누락에서 시작될 수 있습니다.
- Sentinel은 세팅 누락, 승인 필요 항목, 운영 중 다시 봐야 할 이상 신호를 체크리스트로 정리합니다.
- 플래너는 자동 확정된 결과가 아니라 검토 가능한 기준을 보고 판단합니다.

### Capture and Evidence

- Lens는 캡처와 증빙을 보고 가능한 흐름으로 정리합니다.
- 내부 화면이나 민감 정보는 영상과 교육 자료에 그대로 노출하지 않습니다.
- 캡처는 단순 저장이 아니라 "무엇을 확인했고 왜 남겼는지"를 함께 정리하는 과정입니다.

### Forecast and Analysis

- Foresight는 성과를 약속하지 않고 다음 판단을 위한 가설을 제안합니다.
- 분석은 숫자를 맞히는 일이 아니라, 다음 실행에서 무엇을 바꿀지 정하는 과정입니다.
- AdMate는 결과를 다음 브리프, 검수 기준, 운영 메모의 학습 후보로 되돌리는 루프를 지향합니다.

### Closing

- AdMate를 쓰면 플래너는 빈 화면에서 시작하지 않습니다.
- 반복 확인은 줄이고, 판단의 근거는 더 잘 남깁니다.
- 최종 결정은 사람이 하고, AdMate는 그 결정을 더 빠르고 일관되게 준비합니다.

## On-screen Copy 후보

- `Guide source check`
- `Setup validation`
- `Anomaly signal`
- `Capture with context`
- `Forecast as a hypothesis`
- `Planner judgment stays central`
- `Learning loop`

## 금지 문구

- 플래너가 없어도 자동으로 운영됩니다.
- 모든 세팅 사고를 완전히 막습니다.
- AI가 알아서 예산과 소재를 집행합니다.
- 실제 성과를 약속합니다.
- 실제 광고주 화면과 계정 정보를 보여드립니다.

## 교육 영상 주의사항

- 예시는 dummy brand, dummy campaign, dummy number만 사용한다.
- 화면은 실제 내부 화면이 아니라 abstract card 또는 sanitized mock으로 만든다.
- presenter는 실제 선배 플래너처럼 말하지 않고 가상 guide로 말한다.
- "제가 직접 운영해보니" 같은 실제 경험담 표현은 쓰지 않는다.
