# Product One-liners v1

작성일: 2026-05-07
상태: Gate Creative-Studio-1 draft
용도: Compass, Sentinel, Lens, Foresight, Agent Core를 영상/발표에서 짧게 설명하기 위한 승인 문장

## 전체 구조

AdMate는 4개 product Agent와 1개 Core layer로 설명한다.

- Compass: 기획과 방향 설정
- Sentinel: 정책과 운영 안전
- Lens: 캡처와 증빙
- Foresight: 예측 가설과 학습
- Agent Core: 네 Agent를 연결하는 운영 중심 계층

## Executive-friendly One-liners

- Compass는 광고 운영의 출발점을 표준화해 기획 품질의 편차를 줄입니다.
- Sentinel은 정책과 권한 기준을 운영 흐름에 포함해 안전한 AI 활용의 기반을 만듭니다.
- Lens는 운영 기록을 증빙 가능한 형태로 남겨 조직의 설명 책임을 강화합니다.
- Foresight는 성과 보장이 아니라 다음 의사결정에 필요한 학습 구조를 제공합니다.
- Agent Core는 개별 Agent를 하나의 통제된 운영 체계로 묶어 확장 가능한 기반을 만듭니다.

## Planner-friendly One-liners

- Compass는 브리프를 보고 먼저 확인해야 할 조건을 정리합니다.
- Sentinel은 정책 위반 가능성과 세팅 실수를 미리 점검합니다.
- Lens는 캡처와 증빙을 나중에 찾기 쉬운 형태로 정리합니다.
- Foresight는 결과를 보고 다음 액션의 가설을 세우는 데 도움을 줍니다.
- Agent Core는 여러 작업이 따로 놀지 않도록 한 흐름으로 묶어줍니다.

## Product별 Approved Sentence Bank

### Compass

- Compass는 브리프를 실행 가능한 운영 경로로 바꿉니다.
- Compass는 플래너가 가장 먼저 확인해야 할 목표, 채널, 제약 조건을 정리합니다.
- Compass는 전략을 자동 확정하지 않고, 사람이 판단할 수 있는 출발점을 제공합니다.

### Sentinel

- Sentinel은 정책 확인과 검수 기준을 운영 초반에 끌어올립니다.
- Sentinel은 세팅 사고를 줄이기 위해 누락 가능성과 승인 필요 항목을 확인합니다.
- Sentinel은 사람 승인 없이 집행하지 않습니다. 안전한 판단을 위한 신호를 제공합니다.

### Lens

- Lens는 운영 과정의 캡처와 증빙 흐름을 정리합니다.
- Lens는 내부 화면을 그대로 노출하지 않고, 필요한 근거를 비식별 기준으로 다룹니다.
- Lens는 보고를 위한 기록을 남기되, 민감 정보는 영상과 교육 자료에서 제외합니다.

### Foresight

- Foresight는 성과를 보장하지 않고 다음 판단을 위한 예측 가설을 제안합니다.
- Foresight는 실행 결과를 회고하고 다음 브리프와 검수 기준으로 되돌립니다.
- Foresight는 자동 집행보다 운영자가 더 잘 판단하도록 돕는 분석 관점을 제공합니다.

### Agent Core

- Agent Core는 네 Agent가 같은 기준으로 움직이도록 연결합니다.
- Agent Core는 권한, 감사 로그, 승인 흐름을 전제로 AI 운영의 신뢰도를 높입니다.
- Agent Core는 기획부터 학습까지 이어지는 광고 운영 loop의 중심입니다.

## 사용 금지

- 제품이 사람의 최종 판단을 대체한다고 말하지 않는다.
- 제품이 실제 성과를 보장한다고 말하지 않는다.
- 제품이 내부 계정, 광고주 자료, 캠페인 데이터를 영상에 노출한다고 말하지 않는다.
- 제품이 권한 없이 학습하거나 집행한다고 말하지 않는다.
