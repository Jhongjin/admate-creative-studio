## Executive Tone

임원용 메시지는 속도보다 경쟁력, 통제, 비용, 확장성을 먼저 설명한다. AI 기능 자체보다 회사의 운영 자산과 governance 관점에서 말한다.

## Core Narrative

AdMate는 광고 운영의 반복 업무를 AI Agent로 정리하고, 운영자의 판단을 조직의 지식 자산으로 남기는 플랫폼입니다. Compass는 정책/가이드 근거 확인의 출발점을 정리하고, Sentinel은 세팅 검수와 운영 이상 감지 신호를 정리합니다. Lens와 Foresight는 각각 기록과 예측 가설을 담당하고, Agent Core가 이를 권한과 감사 로그 기반의 운영 체계로 연결합니다.

## Approved Executive Sentences

### Opening

- AdMate는 광고 운영 자동화를 넘어, 운영 지식을 회사의 자산으로 만드는 AI Agent 플랫폼입니다.
- 오늘 보고의 핵심은 빠른 생성이 아니라 안전한 운영 자동화와 반복 가능한 품질입니다.
- AdMate의 방향은 미디어플래너를 대체하는 것이 아니라, 플래너의 판단이 더 잘 쓰이고 더 잘 남도록 돕는 것입니다.

### Competitive Advantage

- 회사의 경쟁력은 개별 캠페인을 더 빨리 처리하는 데서 끝나지 않습니다.
- 중요한 것은 운영 기준이 누적되고, 다음 실행에서 다시 활용되는 구조입니다.
- AdMate는 기획, 정책/가이드 근거 확인, 세팅 검수, 캡처, 학습 후보를 하나의 운영 loop로 연결합니다.

### Knowledge Asset

- 운영자의 판단이 매번 문서 밖으로 흩어지면 회사의 지식 자산으로 남기 어렵습니다.
- AdMate는 판단 근거와 검수 기준을 다음 운영에 재사용 가능한 학습 후보로 정리합니다.
- 이 구조는 특정 담당자에게만 의존하지 않는 운영 품질의 기반이 됩니다.

### Repetitive Work Reduction

- 반복 업무 절감은 단순한 생산성 지표가 아니라 운영 품질을 높이는 여유를 만듭니다.
- 정책/가이드 근거 확인, 세팅 검수, 캡처, 보고 준비를 줄이면 플래너는 더 중요한 판단에 집중할 수 있습니다.
- AdMate는 반복 작업을 줄이되, 최종 판단과 승인 책임은 사람에게 남깁니다.

### Governance and Safety

- 안전한 AI 운영은 모델 성능보다 먼저 권한과 감사 가능성에서 출발합니다.
- AdMate는 ISMS, 권한, 감사 로그, 승인 흐름을 전제로 운영되어야 합니다.
- 내부 화면, 계정 정보, 캠페인명, 광고주명은 보고 영상과 교육 자료에 노출하지 않습니다.

### Cost and ROI

- AdMate의 ROI는 성과 약속이 아니라 운영 시간 절감, 오류 예방, 지식 축적 효과로 설명해야 합니다.
- 비용 관리는 AI 사용량뿐 아니라 어떤 업무가 줄었고 어떤 기준이 남았는지까지 함께 봐야 합니다.
- 초기 목표는 무검토 집행이 아니라 반복 업무와 리스크를 줄이는 통제된 적용입니다.

### Roadmap

- 첫 단계는 승인 메시지, dummy dataset, 제작 전 검수 체계를 확립하는 것입니다.
- 다음 단계는 제품별 사용 장면을 정리하고, 사람 승인 기반 workflow를 더 세밀하게 설계하는 것입니다.
- 최종적으로는 기획부터 학습까지 이어지는 광고 운영 loop를 하나의 Agent Core로 관리하는 것이 목표입니다.

## 금지 문구

- AdMate가 광고 운영을 완전히 자동화합니다.
- 사람 승인 없이 AI가 캠페인을 학습하고 집행합니다.
- 성과를 보장합니다.
- 실제 광고주 또는 캠페인 데이터를 기반으로 설명합니다.
- 실제 임직원이 직접 발표하는 영상입니다.

## Reporting Notes

- 수치가 필요하면 실제 수치 대신 측정 프레임을 설명한다.
- 회사 내부 화면은 abstract workflow 또는 dummy mock으로 대체한다.
- presenter는 가상 캐릭터 고지를 반드시 포함한다.
- 보안/권한/감사 로그는 기능 과장 없이 운영 원칙으로 표현한다.
- Openclaw와 Hermes는 Agent Core 내부 엔진으로만 설명하고 별도 외부 제품처럼 강조하지 않는다.
