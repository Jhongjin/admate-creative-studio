# Presenter Voice Tone Guide v1

작성일: 2026-05-07
상태: Gate Creative-Studio-1 draft
용도: AdMate 가상 presenter의 한국어 발표 톤, 문장 길이, 금지 표현 기준

## 기본 역할

AdMate presenter는 차분하고 신뢰감 있는 설명자다. 실제 직원, 임원, 고객, 광고주 담당자가 아니라 생성형 AI로 만든 가상 캐릭터이며, 영상 안팎에서 이 사실을 명확히 고지한다.

## Voice Principles

- 침착함: 빠르게 몰아붙이지 않고 핵심만 또렷하게 말한다.
- 신뢰감: 기능보다 운영 기준, 권한, 검수, 사람의 최종 판단을 먼저 말한다.
- 절제: 과장된 광고 문구, 자극적인 비교, 성과 보장 표현을 피한다.
- 협업성: 미디어플래너를 대체하지 않고 돕는 파트너로 설명한다.
- 투명성: 가상 presenter라는 사실을 숨기지 않는다.

## 한국어 문장 길이 기준

| 용도 | 권장 길이 | 기준 |
|---|---:|---|
| 영상 opening | 20-35자 | 한 번에 기억되는 한 문장 |
| 제품 설명 | 35-55자 | 제품명 1개와 역할 1개만 포함 |
| 임원 보고 내레이션 | 45-70자 | 근거와 의미를 함께 설명 |
| 플래너 교육 내레이션 | 30-55자 | 업무 상황과 도움을 바로 연결 |
| 자막 | 12-24자 | 한 화면에 한 메시지 |

긴 문장은 두 문장으로 나눈다. 한 문장에 제품명, 기능, 효과, 보안 기준을 모두 넣지 않는다.

## 톤 차이

| 구분 | Executive Presenter | Planner Guide |
|---|---|---|
| 속도 | 천천히, 안정적으로 | 조금 더 빠르지만 차분하게 |
| 말투 | 보고형, 단정형 | 안내형, 실무형 |
| 어휘 | 경쟁력, 운영 자산, 권한, 감사 로그, ROI | 정책 확인, 검수, 캡처, 분석, 다음 기준 |
| 강조 | 통제 가능한 AI 운영 | 반복 업무 감소와 판단 지원 |
| 피할 톤 | 스타트업 pitch처럼 과열된 톤 | influencer 후기처럼 사적인 톤 |

## Executive Presenter 문장 예시

- AdMate는 광고 운영 자동화를 넘어, 운영 지식을 회사의 자산으로 만드는 플랫폼입니다.
- 핵심은 완전 자동화가 아니라, 권한과 감사 로그 기반의 안전한 AI 운영입니다.
- 반복 업무 절감은 비용 효율뿐 아니라 운영 품질을 높이는 기반입니다.
- 성과는 보장 문구가 아니라, 다음 판단으로 이어지는 학습 루프로 관리합니다.

## Planner Guide 문장 예시

- 브리프가 들어오면, 먼저 확인해야 할 조건부터 정리합니다.
- 정책 확인과 세팅 검수를 앞단에서 나누면 수정 시간을 줄일 수 있습니다.
- 캡처는 단순 저장이 아니라, 나중에 보고할 근거를 남기는 과정입니다.
- 최종 판단은 플래너가 하고, AdMate는 그 판단을 더 잘 준비하게 돕습니다.

## 가상 presenter 고지 문장

### 내부 영상

`본 영상의 presenter는 생성형 AI로 제작한 가상 캐릭터이며 실제 임직원이 아닙니다.`

### 외부 영상

`본 콘텐츠의 presenter는 AdMate 설명을 위해 생성형 AI로 제작한 가상 캐릭터입니다. 실제 인물 또는 임직원을 나타내지 않습니다.`

### 짧은 caption

`AI-generated virtual presenter`

## 말하지 않는 방식

| 피해야 할 톤 | 예시 | 대체 |
|---|---|---|
| 과장 | "이제 광고 운영은 모두 자동으로 끝납니다." | "반복 업무를 줄이고, 검토 가능한 기준을 만듭니다." |
| 성과 보장 | "성과가 반드시 개선됩니다." | "다음 판단을 위한 예측 가설을 제공합니다." |
| 실제 직원 오인 | "저는 AdMate 운영팀의 담당자입니다." | "저는 AdMate 설명을 위한 가상 presenter입니다." |
| 무승인 집행 | "AI가 알아서 학습하고 집행합니다." | "사람 승인과 권한 기준을 전제로 운영합니다." |
| 내부자료 노출 | "이 실제 캠페인 화면을 보시면..." | "이 예시는 비식별 mock 화면으로 설명합니다." |

## Delivery Notes

- 첫 문장은 낮고 안정적인 톤으로 시작한다.
- 제품명은 한 번에 하나만 강조한다.
- 자막과 내레이션이 같은 문장을 반복하지 않도록, 자막은 짧은 label로 둔다.
- "대체", "완전", "보장", "실제 사례"라는 단어는 script review에서 다시 확인한다.
- 실제 경험담처럼 들리는 1인칭 표현은 피한다.

## Script Review Checklist

- [ ] 한 문장이 너무 길지 않은가?
- [ ] 사람 승인 없는 자동화처럼 들리지 않는가?
- [ ] 실제 직원 또는 실제 고객처럼 보이는 표현이 없는가?
- [ ] 성과 보장으로 들리는 표현이 없는가?
- [ ] 가상 presenter 고지가 포함되어 있는가?
- [ ] 내부 화면, 캠페인명, 광고주명, 계정 정보가 없는가?
