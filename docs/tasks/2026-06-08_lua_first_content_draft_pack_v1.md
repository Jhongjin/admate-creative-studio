Status: draft-copy-only

## Boundary

This pack contains copy, structure, disclosure, alt text, and review checklist
only.

Not approved:

- image/video/audio generation,
- media upload,
- publishing,
- promotion,
- account login/2FA handling by Codex,
- provider/API/SaaS calls,
- `AI Influencer/` file inspection, upload, movement, staging, or commit.

influencer channel, not Lua's entire identity.

Review notes:
